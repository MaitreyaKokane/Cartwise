# 🛍️ ShopPilot AI

**Intelligent Shopping, Grounded in Data.**

🚧 **Status: Work in Progress**

ShopPilot AI is a full-stack AI shopping assistant designed to help users discover products, compare specifications, and receive personalized recommendations through natural-language conversations.

The project aims to combine **LLMs, Retrieval-Augmented Generation (RAG), semantic search, and tool calling** with a modern web application to deliver useful, evidence-grounded shopping recommendations.

### Planned Technologies
- **Backend:** Python, FastAPI
- **Frontend:** React, TypeScript, Tailwind CSS
- **Database:** PostgreSQL with pgvector
- **AI:** LLM integration, embeddings, RAG, and tool calling
- **Deployment:** Docker and cloud infrastructure

### Current Status
The project is under active development. Features, architecture, and implementation details may evolve as development progresses.

The goal is to build a reliable, end-to-end AI application while exploring practical LLM engineering, API design, evaluation, and deployment.
